# Docker Compose Template

Docker Compose stack with Traefik, Tinyauth, Pocket ID, and 20+ self-hosted services.

## Quick Start

1. Set up a server (see [VPS Setup Guide](guides/vps-setup.md) for Oracle Cloud)
2. Clone the repo and deploy (see [Template Deployment Guide](guides/template-deployment.md))

## Prerequisites

- Linux server with Docker
- Domain name pointing to your server's IP
- Ports 80 and 443 open in firewall
- Cloudflare account (recommended)
